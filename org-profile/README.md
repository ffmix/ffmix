### FFmix

**A native macOS frontend for FFmpeg — the command you see is the command that runs.**

Drop in media → pick a task or describe it in a sentence → review the exact ffmpeg pipeline → run it locally. Files never leave your Mac.

- 📦 [**ffmix/ffmix**](https://github.com/ffmix/ffmix) — docs, battle-tested [ffmpeg recipes & gotchas](https://github.com/ffmix/ffmix/blob/main/docs/ffmpeg-recipes.md), the reproducible [LGPL engine build](https://github.com/ffmix/ffmix/tree/main/engine), devlog, and the app's public issue tracker
- 🌐 [ffmix.com](https://ffmix.com) — the product
- 🛠 Building in public — [devlog](https://github.com/ffmix/ffmix/tree/main/devlog)

Built on the shoulders of [FFmpeg](https://ffmpeg.org), [whisper.cpp](https://github.com/ggml-org/whisper.cpp), and [friends](https://github.com/ffmix/ffmix/blob/main/ACKNOWLEDGMENTS.md).
